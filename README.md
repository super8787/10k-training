# 10K 訓練 App

11 週從 2 公里練到 10 公里的訓練計畫，做成手機可用的網頁 App。

## 這是什麼

一份**會依實際表現自動調整**的跑步課表。不是靜態的訓練表——它讀你的訓練紀錄，
用七條寫死的規則判斷該加量、該降階、還是該休息，而且每條建議都會標明是哪條規則觸發的。

**核心觀點：** 新手跑不完 10K 通常不是體能不夠，是**跑太快**。
所以這份計畫的第一優先指標不是配速，是「輕鬆跑有多少比例待在 Z2 心率」。

## 怎麼用

iPhone Safari 開啟 → 分享 → **加入主畫面**。之後就跟一般 App 一樣，
有圖示、全螢幕、離線可開。

## 資料放哪

訓練紀錄**只存在你自己的手機**（localStorage），不會上傳任何地方。
這個 repo 只有課表與程式碼。

真正的原始資料在 iPhone 的「健康」App，所以就算把 App 資料清掉也還原得回來。

## 結構

```
index.html   外殼與底部頁籤
app.js       畫面渲染、記錄、匯入匯出
coach.js     自動調整引擎（七條規則，純函式）
plan.json    11 週課表（由 build_plan.py 產生，勿手改）
sw.js        Service Worker，離線用
```

課表不要直接改 `plan.json`——改產生器再重跑，它帶自動驗證
（週增幅上限、減量週、心率區間一致性、長跑佔比）。
